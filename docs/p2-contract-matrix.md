# P2 页面接入矩阵

状态：2026-11-20，按用户要求仅工程化页面与 Mock，Live 接口留空。

| 页面/组件 | 领域能力 | Mock 交付 | Live |
| --- | --- | --- | --- |
| `/practice` / 提交历史 | 概览、状态筛选、分页、待改进 | 独立会话存储查询 | 待契约 |
| `/practice/new` / 表单 | 草稿、读取文本、自测、授权、创建快照 | 校验、版本冲突、幂等提交 | 待契约 |
| `/practice/[id]` / 评审 | 快照、进度、重试、历史版本 | 时间驱动的明确模拟，追加评审 | 待契约 |
| 结果/证据/改进/追问 | 五维评分、定位、标记与回答 | 预置结果，持久化模拟写入 | 待契约 |
| `/dashboard` 代码区块 | 7/30 天统计、最近提交 | 同一 Mock 数据集聚合 | 待契约 |

模型在 `lib/practice/types.ts`，不能当作后端 DTO。Live 统一返回 NOT_CONNECTED，不发送猜测的端点、不回退 Mock。页面调用 `lib/practice/service.ts`，未来只替换领域 Live 适配器。

URL 仅保存业务筛选/定位：`/practice?status=failed&page=1`、`/practice/new?copy=提交ID`、`/practice/new?task=任务ID`、`/practice/提交ID?review=评审ID`。数据源仍只由启动/构建命令决定。

Mock 口径：每次提交只统计最新评审，按提交日期归集；只有最新已评分结果进入均分/最高分；自测按所选范围用例汇总；改进项取最新已结束评审。此口径仅供预览，正式规则待后端确认。

独立性和评审授权默认不勾选。Mock 本地保存仅用于演示，不调用 AI、不执行代码；未来第三方提供方、保留策略、授权版本、幂等/分页/评分/限流等均在 Live 接入前定约。复制旧提交只产生新草稿，不覆盖旧代码。提交不自动完成 P1 任务。

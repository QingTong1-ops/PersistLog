# P2 Mock 页面交付与验收

日期：2026-11-20。范围：原型 `design/p2p3/` 对应的 P2 React 页面，不包含 P3 或真实接口联调。

## 入口

```powershell
pnpm dev:mock
# 或 npm run dev:mock
```

在 `/login` 使用预填演示账户进入；`/practice` 为提交历史，`/practice/new` 为提交表单，`/practice/04` 为预置成功评审，`/practice/01` 为失败记录，`/practice/06` 为证据不足。`/dashboard#code-feedback` 为代码趋势区块。

Live 模式仍保留路由守卫，登录后 P2 页面显示“接口待接入”，不猜测接口、不请求评分、不回退 Mock。P1 仍使用原有真实接口。原型中的目录页和 P3 跳转不复制为生产能力。

## 本轮实现

- 桌面导航、面包屑和移动功能目录；保留原 P1 底部四入口。
- 状态筛选、分页、整行历史链接；7/30 天代码统计取同一演示数据集。
- 自由提交或从 P1 今日/路线任务进入；只关联来源，不自动完成 P1 任务。
- 草稿保存/恢复/删除、版本冲突、复制旧提交为新草稿、文件本地读取与替换确认、200 KiB 字节限制、自测/复杂度/确认校验。
- 提交后代码快照只读；模拟任务约 8 秒完成，进度放在 Mock 数据源，离页/刷新继续查询，不在 React 里补造评分。
- 待评审/处理中/成功/失败/证据不足；重评追加记录，历史结果独立访问；失效 ID 显示错误。
- 左代码右反馈；1100px 以下单列；行号证据定位；过程摘要键盘展开和刷新偏好恢复。
- 最多三项改进的显式保存/失败回滚；逐条追问回答保存；不接入 P3 提问页。
- 代码区块独立加载/错误处理，不影响 P1 看板；空评分点不补 0。

Mock 存储键 `persistlog:mock:practice:v1`，按 P1 演示身份创建时间隔离；当前标签页刷新可恢复，重置演示会清除 P2 数据。仅演示模式保存这些内容，不应输入真实代码或敏感信息。Live 的草稿保存与授权范围仍待后端定约。

## 自动化测试复现

领域测试复用既有 Node harness：`pnpm test:p2`，全量模式测试 `pnpm test:modes`。不新增生产依赖。

可选浏览器验收依赖独立安装到被忽略的目录：

```powershell
npm install --prefix .preview/p2-browser --no-package-lock --ignore-scripts playwright-core@1.65.1
pnpm build:mock
pnpm build:live
pnpm test:p2:browser
```

默认使用本机 `C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe` 的无头实例，不使用个人浏览器资料。其他环境可设置 `BROWSER_EXECUTABLE` 和 `PLAYWRIGHT_CORE_PATH`。测试自行使用空闲端口并只关闭自己启动的服务，不连接真实后端。当前执行环境没有 pnpm 命令，实际运行的是 package.json 对应的 Node 入口。

浏览器产物保存于 `.preview/p2-checks/`（不提交），包括结果 JSON 与截图。

### 实测覆盖

- 失败历史 → 追加重试 → 刷新 → 演示结果；旧失败仍保留。
- 证据按钮定位代码行；改进标记、追问回答刷新后保留；过程摘要通过 Enter 展开并恢复。
- 复制历史 → 修改 → 保存草稿 → 刷新恢复；非法自测显示字段错误；超限文件不覆盖代码；文本读取 → 未自测提交 → 证据不足。
- `1280×720`、`584×761`、`1440×900`、`390×844` 截图检查；额外在 1101/1100、861/860、641/640、421/420 宽度验证主列定位、单双列重排和页面横向宽度。
- 移动功能目录可进入提交表单；reduced-motion 下内容可读；看板 7/30 天切换。
- P1 路线任务可以带上下文进入代码提交；P2 提交后 P1 已完成任务数不变。
- Mock 浏览器未发起 `/api/v1` HTTP 请求，未出现页面异常。Live 测试仅拦截 P1 登录响应以进入受保护页面，确认 P2 显示待接入且没有 P2 网络请求；这不是 Live 后端联调。

## 本轮不作出的承诺

- 无真实 AI、持久化数据库、服务端权限、跨设备恢复或真实后端幂等验收。
- 模拟评分固定示例，不是对用户代码的真实分析；统计去重规则是预览口径，正式规则以后端为准。
- 没有新增自定义弹窗/抽屉：文件覆盖等使用浏览器确认；未声称已有 P1 Sheet 已满足完整焦点陷阱验收。
- 复盘答案的并发保存采用演示版本冲突；真实跨用户/跨标签权限、限流、数据保留策略待 Live 对接。
- 本轮覆盖主要流程，不等于所有大数据、浏览器/设备组合都已测试。P3 仍未开始。

## 3. 当前可用能力

### 账户与配置

- JWT access token（响应体/内存）+ 轮换 refresh token（HttpOnly Cookie）
- 刷新令牌重放检测：撤销用户全部活跃 refresh token
- `Origin` 白名单校验，防跨站 Cookie 写操作
- Argon2id 密码哈希
- 用户时区、日界线、每日可用分钟、容量系数
- 求职目标 CRUD、主目标切换、归档
- 授权同意记录

### 计划导入

- 上传 `.md` / `.markdown` 到本地存储
- 解析标题、阶段、周、任务、时长、产出、验收、日期
- AI 标准化：支持 Stub 与 OpenAI-compatible（DeepSeek `deepseek-flash`）；失败回退规则解析
- 导入校验：日期平移、容量分配、缺失字段、重复任务；预览返回 assumptions/warnings/issues
- 预览、编辑、确认、取消、回滚
- 确认后生成路线、阶段、周、任务、路线版本
- 异步导入 + `GET /jobs/{id}` 轮询；Broker 不可用时请求内降级
- `Job` / `AiRun` 审计记录

### 路线与任务

- 路线 CRUD、激活/暂停/恢复/归档
- 调整开始日期/每日容量，并平移阶段、周、任务日期
- 路线版本快照与版本详情
- 阶段/周/任务 CRUD
- 任务归档、路线任务归属校验
- 同一求职目标下只保留一条执行中路线

### 每日执行

- 每日计划生成：容量、优先级、最多 6 项
- 跨日顺延，保留来源和顺延次数
- 今日视图：计划/完成/实际分钟/完成率/顺延任务
- occurrence 状态：开始、完成、延期、跳过、阻塞、解除阻塞、放弃、拆分
- 路线进度按已完成 occurrence 计算
- 预测剩余分钟、吞吐、预测完成日期

### 看板

- 单日/区间总览：完成率、计划/实际分钟、顺延率、路线进度
- 按天趋势
- 按任务类型/路线/状态/优先级分布
- 聚合预测和每路线预测
- 看板与今日页、路线详情已对账

### 通知

- 企微群机器人渠道 CRUD、测试发送
- Webhook 严格校验：HTTPS、固定 host/path、key 格式、禁止重定向
- Webhook 使用 Fernet 加密存储，接口只返回 masked
- 模板渲染、偏好、免打扰 delay/drop
- Outbox：去重、1/5/30 分钟重试、3 次重试后 dead、手动重发
- Celery 任务：早报、晚报、逾期、顺延、周总结
- 真实 Redis + worker/beat 已验证；真实企微五类通知均已发送成功
- 测试环境使用 Logging Provider，不访问外网

### 硬化

- 审计：导入确认、路线调整、通知渠道创建/修改/删除
- 限流：登录 5 次/分钟/IP；导入 3 次/小时/用户；通知测试 5 次/小时/用户
- 统一错误包与 `X-Request-ID`
- 日志敏感字段脱敏
- OpenAPI 检查
- E2E 测试

## 6. 已知限制与未完成项

1. **前端未实现**：当前只有后端 API 和 OpenAPI 文档，没有 Web/移动端页面。
2. **Phase 2/3 未实现**：代码静态评审、AI 诊断、错题复习等均不在当前范围；没有代码执行、沙箱、CLI/IDE。
3. **真实 AI 已接但质量未评估**：当前使用 DeepSeek `deepseek-flash`；样本量小，结构化合法率和字段完整率还需用 10 份真实计划评估；失败会降级规则解析。
4. **企微密钥需轮换**：真实 Webhook 已写入本地 `.env`/数据库密文，不在仓库；如怀疑泄露，应在企微后台重建机器人并更新渠道。
5. **Worker/Beat 不是 Windows 服务**：Redis 已配置计划任务 `persistLog-Redis` 登录自启（注销后可能停止）；Worker/Beat 仍需登录后手动运行 `scripts/start_worker.ps1`、`start_beat.ps1`。若要做成登录前/跨会话系统服务，需要管理员权限。
6. **偏好中的 send_time 未做动态调度**：偏好字段已存储，当前 beat 仍按默认时间（07:30/20:30 等）运行。
7. **M3–M8 没有增量迁移**：Phase 1 所需表都在 baseline `0001_initial`，这些模块没有新增字段；升级/回滚按 baseline 验证。
8. **审计覆盖范围有限**：当前记录导入确认、路线调整、通知渠道 CRUD；没有批量删除接口，因此未覆盖批量删除审计。
9. **生产备份未实际演练**：README 已写 `mysqldump`/恢复命令，但未在真实生产库执行；恢复前必须先确认目标库。
10. **认证契约已变更**：登录/注册/刷新响应不再返回 `refresh_token`，前端必须依赖 HttpOnly Cookie；接入前端前需确认跨域/同源部署方式。
11. **限流降级**：本地/测试使用内存限流；生产优先 Redis，Redis 不可用时会降级到进程内存，不能跨进程共享。
12. **旧 `storage/` 目录不可写**：当前 Windows 账户对历史 `storage/` 无写权限；测试改用 `storage_test/`，本地启动 API 时需把 `STORAGE_DIR` 指到可写目录（如 `storage_test` 或新建 `storage_dev`）。

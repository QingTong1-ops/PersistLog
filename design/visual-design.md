# 恒序 persistLog 视觉与页面设计

## 1. 设计方向

### 设计主题：静谧推进 Quiet Momentum

恒序不是一个制造压力的打卡工具，而是一个帮助用户持续向目标岗位靠近的个人成长系统。视觉上需要同时传达：

- **秩序感**：计划、阶段和任务关系清楚。
- **技术感**：适合计算机专业求职场景，但不使用过重的代码编辑器风格。
- **成长感**：强调能力差距正在缩小，而不是只强调未完成任务。
- **陪伴感**：AI 是教练和复盘伙伴，不是批评者。

关键词：`克制`、`清晰`、`坚定`、`有证据的成长`。

## 2. 品牌视觉语言

### 品牌图形

使用由两条递进曲线和一个定位点组成的符号：

- 两条曲线代表计划与执行。
- 定位点代表当前能力位置。
- 向右上方的走势代表持续进步。

图形应避免使用火焰、奖杯、连续打卡等强游戏化元素。

### 视觉层级

1. 今日最重要的行动。
2. 目标岗位差距和当前进展。
3. AI 建议与复盘证据。
4. 详细记录和配置。

## 3. 配色系统

### 主色

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--brand-600` | `#5B5CE2` | 主按钮、进度、重点链接 |
| `--brand-700` | `#4849B8` | 悬停、深色强调 |
| `--brand-100` | `#E9E9FF` | 浅色背景、标签 |
| `--ink-950` | `#111827` | 深色侧边栏、标题 |
| `--ink-900` | `#172033` | 主文字 |
| `--ink-600` | `#667085` | 次要文字 |
| `--ink-400` | `#98A2B3` | 辅助文字、占位 |
| `--canvas` | `#F6F8FC` | 页面背景 |
| `--surface` | `#FFFFFF` | 卡片和输入框 |
| `--line` | `#E7EAF2` | 边框和分割线 |

### 能力状态色

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--teal-600` | `#16A394` | 已掌握、完成、增长 |
| `--teal-100` | `#DDF7F2` | 成长标签背景 |
| `--amber-600` | `#D88A1B` | 待复习、注意 |
| `--amber-100` | `#FFF1D6` | 复习提示背景 |
| `--coral-600` | `#D85B66` | 阻塞、风险、逾期 |
| `--coral-100` | `#FFE5E7` | 风险提示背景 |
| `--sky-600` | `#3283C8` | 信息、工程化、链接 |
| `--sky-100` | `#E4F1FC` | 信息标签背景 |

### 使用原则

- 主色只用于行动和进度，不大面积铺满页面。
- 绿色代表“有证据的掌握”，不代表单纯完成打卡。
- 琥珀色代表需要复习或关注，不使用刺眼的纯黄色。
- 红色只用于阻塞和真正影响计划的风险。

## 4. 字体与排版

```css
font-family: Inter, "Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif;
```

- 页面标题：28～32px，字重 700。
- 卡片标题：16～18px，字重 650。
- 正文：14px，行高 1.65。
- 辅助信息：12～13px，颜色使用 `--ink-600`。
- 数字指标：24～36px，使用等宽数字或 `font-variant-numeric: tabular-nums`。

## 5. 组件规范

### 卡片

- 背景：白色。
- 圆角：18px。
- 边框：`1px solid var(--line)`。
- 阴影：只在悬停或重点卡片使用轻微阴影。
- 内边距：20～24px。

### 按钮

- 主按钮：品牌紫色，文字白色，圆角 10px。
- 次按钮：白色背景，边框和深色文字。
- 文字按钮：无背景，使用品牌色。
- 破坏性操作：使用珊瑚色，并明确操作对象。

### 状态标签

标签应同时包含文字和颜色，不依赖颜色单独传达状态。例如“待复习”“已掌握”“阻塞”，而不是只显示一个色点。

### 进度表达

优先使用：

- 进度环：今日任务完成度。
- 横向进度条：能力达成度。
- 趋势线：最近 7 天或 30 天变化。
- 证据列表：支撑能力判断的练习和回答。

避免使用只有一个大数字、没有证据来源的 AI 评分。

## 6. 首页信息架构

### 桌面端

```text
┌──────────────┬───────────────────────────────────────────────┐
│ 品牌与导航    │ 顶部问候、目标岗位、通知和个人入口               │
│              ├───────────────────────────────────────────────┤
│ 今日          │ 今日进度主卡 + AI 建议                         │
│ 成长看板      ├──────────────────────┬────────────────────────┤
│ 学习路线      │ 今日重点任务           │ 目标差距 / 能力进度       │
│ 练习          ├──────────────────────┼────────────────────────┤
│ 错题复习      │ 接下来                 │ 已具备能力 / 预计完成日期  │
│ 简历与目标    │                        │                        │
│ 设置          │                        │                        │
└──────────────┴──────────────────────┴────────────────────────┘
```

### 移动端

移动端只保留四个核心入口：

- 今日。
- 看板。
- 复习。
- 我的。

## 7. 首页原型内容

首页第一版展示：

1. 当前日期和问候语。
2. 今日任务完成度。
3. 预计学习时长、已用时长和剩余缓冲。
4. 今日最重要的三项任务。
5. AI 教练建议。
6. 目标岗位能力差距。
7. 已具备能力，例如 MySQL 八股、贪心算法。
8. 预计完成日期和顺延天数。
9. 最近一次复盘结果。

## 8. 交互原则

- 首页默认展示“今天可以做什么”，而不是展示全部历史数据。
- 每个任务都要有明确动作和产出。
- 用户完成任务后立刻看到它对能力看板的影响。
- AI 建议必须提供“为什么这样建议”的证据入口。
- 任务顺延时显示影响范围和新的预计完成日期。
- 所有高风险操作都可撤销或恢复。

## 9. 可访问性与响应式

- 正文与背景对比度至少达到 WCAG AA。
- 不用颜色作为唯一状态标识。
- 所有按钮支持键盘操作。
- 进度环提供文本百分比。
- 低宽度屏幕下，卡片改为单列排列。
- 左侧导航在移动端变为底部导航。

## 10. 原型范围

当前配套原型文件为 `persistlog-prototype.html`，包含：

- 桌面端工作台布局。
- 侧边导航。
- 今日任务交互。
- 进度环和能力进度条。
- AI 教练卡片。
- 自动顺延提示。
- 响应式移动端布局。

原型采用纯 HTML、CSS 和少量 JavaScript，不依赖外部图片和第三方组件库，方便后续直接迁移为 React 页面。

## 当前 P2 / P3 基准

进入 **[P2 / P3 页面原型](p2p3/index.html)**，接入说明见 **[p2p3/README.md](p2p3/README.md)**。

- P2：可查看详情的代码提交历史、网页代码提交、独立异步评审与代码评分趋势。
- P3：诊断与路线生成、每日文字提问、错题复习、能力证据、复习设置。
- 全部使用演示数据，不调用 AI、不上传或执行代码、不保存账户数据。
- 沿用 P1 React 页面的视觉与响应式规则；通用协作要求见 [P1 页面设计协作规范](../docs/frontend-design-guidelines.md)。
